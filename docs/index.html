Every morning this brief works out the most a grid battery in Finland could earn today by charging when electricity is cheap and selling it back when it is expensive. It uses today's Finnish electricity prices, which are set the day before. The example battery charges and discharges at up to 1 megawatt and stores 2 megawatt-hours.
